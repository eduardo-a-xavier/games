# Ícones de item / interação

O protótipo ainda não tem um sistema de inventário completo (ver pendências em `prototype/web/ASSETS.md`), mas já usa ícones para o **botão de interação contextual** (`prototype/web/src/interactable.js` + `world.js`), hoje emoji:

| Uso | Emoji atual |
|---|---|
| Conversar com NPC | 💬 |
| Pegar item do chão | ✋ |
| Abrir baú | 🎁 |
| Colher/interagir com plantação | 🧺 |
| Entrar (porta) | 🚪 |
| Investigar | 🔍 |
| Observar entidade neutra (Saci) | 🌀 |

Quando o inventário existir de fato (itens de crafting, equipamentos, consumíveis — ver `docs/GDD.md` Seções 17–21), os ícones de item por categoria entram aqui, um arquivo por item/categoria, convenção de nome `<id_do_item>.png`.
