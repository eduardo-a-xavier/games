# Vagalume de Defunto

Dados de referência puxados de `prototype/web/src/bestiary.js` (id: `vagalume_de_defunto`) — qualquer atualização de lore/comportamento deve ser feita lá primeiro; este arquivo só documenta pra quem for desenhar a criatura.

**Categoria:** Hostil
**Habitat:** Mata do Cedro, Brejo das Lanternas
**Horário/condição:** night
**Agressividade:** 2

**Comportamento:** Aparece em grupos pequenos à noite; voa em padrão errático; luz confunde o jogador.

**Ataques:** Luz Confusa (inverte controles por instantes), Toque Elétrico
**Fraquezas:** Dano mágico
**Resistências:** Dano físico leve
**Drops:** Pó de Vagalume

**Lore:** Diz-se que carregam a última luz de quem se perdeu na mata sem encontrar o caminho de volta.

**Relação com o Encantado:** Naturalmente ligado ao Encantado — só fica hostil perto de Veios perturbados.

**Pista visual de corrupção (obrigatória se aplicável):** Luz que pulsa em vermelho em vez de amarelo quando corrompido.

**Implementado no protótipo:** não — só dados nesta etapa
