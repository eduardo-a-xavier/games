# Onça de Bruma

Dados de referência puxados de `prototype/web/src/bestiary.js` (id: `onca_de_bruma`) — qualquer atualização de lore/comportamento deve ser feita lá primeiro; este arquivo só documenta pra quem for desenhar a criatura.

**Categoria:** Hostil
**Habitat:** Serra da Onça (fora do MVP), avistada raramente na Mata do Cedro
**Horário/condição:** neblina
**Agressividade:** 4

**Comportamento:** Mini-boss. Predador raro que desaparece na neblina e reaparece para um ataque surpresa.

**Ataques:** Emboscada na Neblina, Investida Tripla
**Fraquezas:** Luz concentrada
**Resistências:** Furtividade — ignora detecção comum enquanto na neblina
**Drops:** Presa de Bruma, Pelagem Nebulosa

**Lore:** Predadora que aprendeu a caçar entre os dois mundos, nunca totalmente em nenhum deles.

**Relação com o Encantado:** Não corrompida — uma entidade nativa do Encantado que caça no lado humano.

**Implementado no protótipo:** não — só dados nesta etapa
