# Curupira

Dados de referência puxados de `prototype/web/src/bestiary.js` (id: `curupira`) — qualquer atualização de lore/comportamento deve ser feita lá primeiro; este arquivo só documenta pra quem for desenhar a criatura.

**Categoria:** Guardiã
**Habitat:** Mata do Cedro inteira (território)
**Horário/condição:** any
**Agressividade:** condicional

**Comportamento:** Territorial/guardião: não ataca por padrão. Reage à Perturbação da Mata (ver GDD Seção 34) — acima de um limiar, atrapalha a navegação do jogador como aviso antes de qualquer punição maior.

**Ataques:** Confundir Trilhas (não-letal)
**Fraquezas:** —
**Resistências:** Praticamente invencível em combate direto — não é pensado como inimigo derrotável
**Drops:** —

**Lore:** Protetor da mata, pés virados para trás para confundir quem a agride demais.

**Relação com o Encantado:** Guardião nativo do Encantado, hostil apenas à destruição excessiva, não ao jogador em si.

**Implementado no protótipo:** não — só dados nesta etapa
