# Cão da Estrada

Dados de referência puxados de `prototype/web/src/bestiary.js` (id: `cao_da_estrada`) — qualquer atualização de lore/comportamento deve ser feita lá primeiro; este arquivo só documenta pra quem for desenhar a criatura.

**Categoria:** Hostil
**Habitat:** Estrada Velha
**Horário/condição:** madrugada
**Agressividade:** 3

**Comportamento:** Só se manifesta na madrugada; segue viajantes solitários por longas distâncias antes de atacar.

**Ataques:** Perseguição, Mordida Sombria
**Fraquezas:** Luz, Dano mágico
**Resistências:** Medo (imune)
**Drops:** Coleira Enferrujada

**Lore:** Assombração de um cão que morreu protegendo seu dono numa estrada esquecida.

**Relação com o Encantado:** Presença espiritual antiga, anterior aos Veios — não é corrompido, é assombração natural.

**Implementado no protótipo:** não — só dados nesta etapa
