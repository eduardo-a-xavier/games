# Espantalho Possuído

Dados de referência puxados de `prototype/web/src/bestiary.js` (id: `espantalho_possuido`) — qualquer atualização de lore/comportamento deve ser feita lá primeiro; este arquivo só documenta pra quem for desenhar a criatura.

**Categoria:** Hostil
**Habitat:** Plantações abandonadas, Sítio (raro)
**Horário/condição:** night
**Agressividade:** 3

**Comportamento:** Finge estar inerte até o jogador se aproximar; então ataca de surpresa.

**Ataques:** Emboscada, Golpe de Palha Afiada
**Fraquezas:** Fogo
**Resistências:** Perfuração
**Drops:** Palha Amaldiçoada

**Lore:** Espantalhos abandonados por tempo demais às vezes atraem algo que não é mais só palha.

**Relação com o Encantado:** Vaso para pequenos espíritos errantes ligados a terras negligenciadas perto de um Veio.

**Pista visual de corrupção (obrigatória se aplicável):** Costuras que brilham fracamente em roxo.

**Implementado no protótipo:** não — só dados nesta etapa
