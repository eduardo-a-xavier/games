# Corpo-Seco

Dados de referência puxados de `prototype/web/src/bestiary.js` (id: `corpo_seco`) — qualquer atualização de lore/comportamento deve ser feita lá primeiro; este arquivo só documenta pra quem for desenhar a criatura.

**Categoria:** Hostil
**Habitat:** Mata do Cedro, Brejo das Lanternas
**Horário/condição:** night
**Agressividade:** 4

**Comportamento:** Errático e imprevisível; alterna entre lento e explosivamente rápido.

**Ataques:** Investida Errática, Sufocamento
**Fraquezas:** Água benta / itens de Benzedeiro (futuro)
**Resistências:** Dano físico leve
**Drops:** Vínculo Podre

**Lore:** Segundo a lenda, é o corpo de quem morreu sem enterro digno e sem parte de sua alma.

**Relação com o Encantado:** Atraído por Veios como forma de tentar se completar novamente.

**Pista visual de corrupção (obrigatória se aplicável):** Pele rachada com fumaça escura escapando das fendas.

**Implementado no protótipo:** não — só dados nesta etapa
