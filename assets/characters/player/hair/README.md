# Cabelo — camada de aparência

Uma opção de estilo × uma de cor (`prototype/web/src/appearance.js` → `EN.Appearance.hairStyles` / `hairColors`). Mesmo grid 40×56px e âncora (20,40) do `base/` — ver `assets/art_direction/CHARACTER_STYLE_GUIDE.md`.

**Estilos definidos hoje:** curto, cacheado, longo, coque, raspado.
**Cores definidas hoje:** preto, castanho, ruivo, grisalho, loiro (hex exatos em `palette_reference.png`).

Convenção de nome sugerida: `<estilo>_<cor>.png` (ex.: `curto_castanho.png`), um frame só por combinação (o cabelo não precisa de spritesheet de animação própria — ele acompanha o frame do corpo).
